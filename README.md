# CS 300 Portfolio Reflection

## What was the problem you were solving in the projects for this course?

The main problem I worked on in this course was finding an effective way to organize, store, search, and display course information. In Project One, I compared different data structures, including vectors, hash tables, and binary search trees. I analyzed their run-time efficiency and memory usage to determine which structure would work best for the advising program. In Project Two, I used what I learned to create a working C++ program that loads course information, stores the courses, and prints the course list in alphanumeric order. The program also allows a user to search for a specific course and view its prerequisites.

## How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by first understanding what the program needed to accomplish and then comparing the advantages and disadvantages of different data structures. I learned that choosing the correct data structure can have a major impact on how efficiently a program runs. For example, some structures make searching faster, while others make sorting or inserting information easier. Understanding vectors, hash tables, and binary search trees helped me think about more than just whether a program works. I also had to consider how efficiently it works and how the program might perform with a larger amount of data.

## How did you overcome any roadblocks you encountered while going through the activities or project?

One of the challenges I encountered was making sure the course data was loaded correctly and that prerequisites were connected to the correct courses. I also had to make sure the binary search tree handled the course information properly and printed the courses in the correct alphanumeric order. I worked through these problems by reviewing my code in smaller sections, testing the program frequently, and correcting errors as I found them. Breaking the project into smaller steps made debugging easier and helped me understand how each part of the program worked with the others.

## How has your work on this project expanded your approach to designing software and developing programs?

This project changed the way I approach software development because I now think more carefully about program design before I begin writing code. Instead of immediately starting to code, I consider what information needs to be stored, how it will be accessed, and which data structure is appropriate for the problem. I also learned the importance of considering efficiency, scalability, and organization when designing a program. These are skills that I can apply to larger and more complicated software projects in the future.

## How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

My work in this course has helped me become more aware of writing code that another programmer can understand and maintain. I learned to use meaningful variable and function names, organize code into separate functions, add useful comments, and avoid unnecessary repetition. I also learned that programs should be designed so changes can be made without having to rewrite everything. Writing readable and organized code makes debugging easier and allows a program to be expanded or adapted in the future.

Overall, CS 300 helped me better understand how data structures and algorithms affect software performance and design. The projects gave me experience comparing different solutions and selecting an appropriate data structure for a specific problem. I will be able to use these skills in future computer science courses and software development projects.
